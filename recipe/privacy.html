앱이소 레시피 개인정보처리방침

최종 수정일: 2026년 9월 4일

요약 — 앱이소 레시피는 개인정보를 수집하지 않습니다. 계정도, 로그인도, 광고도, 분석 도구도 없습니다. 적어 둔 레시피와 조리 기록, 찍은 요리 사진은 모두 사용자의 휴대폰 안에만 저장되며 개발자를 포함한 누구에게도 전송되지 않습니다.

1. 수집하는 개인정보

  • 이 앱은 이름, 이메일, 전화번호, 위치, 연락처 등 어떤 개인정보도 수집하지 않습니다.
  • 회원가입·로그인 기능이 없으며 사용자를 식별하지 않습니다.
  • 사용 기록을 수집하는 분석 도구(애널리틱스)나 광고 SDK를 넣지 않았습니다.

2. 앱에 저장되는 내용

사용자가 만든 레시피(재료·조리 단계·버전), 조리 기록과 맛 평가, 요리 사진, 화면 설정은 안드로이드의 앱 전용 저장 공간에 휴대폰 안에만 저장됩니다. 로그인이 없으므로 이 데이터가 아래에서 설명하는 구글 자동 백업 외의 다른 어떤 곳에도 저장되지 않으며, 개발자는 이 내용을 볼 수 없습니다.

사진은 사용자가 앱 안의 카메라 버튼을 직접 눌렀을 때만 찍히며, 그 사진은 조리 단계나 완성 기록에 붙여 앱 전용 저장 공간에 보관됩니다. 앱이 사용자의 사진첩을 읽어 들이거나 사진을 외부로 보내는 일은 없습니다.

이 앱은 안드로이드의 자동 백업을 켜 둔 상태입니다. 기기에서 백업을 켜 두셨다면 레시피·조리 기록·사진이 사용자 본인의 구글 계정 백업에 담길 수 있고, 같은 구글 계정으로 로그인한 새 기기에서 복원될 수 있습니다. 폰을 바꿔도 쌓아 둔 레시피가 사라지지 않도록 하기 위한 안드로이드 기능이며, 백업은 사용자 본인의 계정에만 저장되고 개발자에게는 전달되지 않습니다. 백업을 원치 않으시면 기기 설정에서 이 앱의 백업을 끄시면 됩니다.

3. 공유와 백업 파일

레시피를 텍스트나 파일로 공유하거나, 전체 데이터를 백업 파일로 내보내는 기능은 사용자가 직접 실행했을 때만 동작합니다. 내보낸 내용은 사용자가 고른 앱이나 저장 위치로만 전달되며, 개발자에게는 전송되지 않습니다. 텍스트 공유에는 사진이 포함되지 않습니다. 자랑 카드는 완성 사진 한 장과 레시피 이름·버전·만족도만 담은 이미지 파일로, 역시 사용자가 직접 [이미지로 공유]를 눌렀을 때만 만들어져 사용자가 고른 앱으로 전달됩니다.

레시피 한 개를 담은 .recipe 파일에는 그 레시피의 재료·조리 단계와, 사용자가 [사진 포함]을 켰을 때 크기를 줄인 사진 사본이 함께 들어갑니다. 맛 평가 기록은 들어가지 않습니다. 반대로 다른 앱에서 .recipe 파일을 열면 그 내용은 추가할지 확인을 받은 뒤에만 이 기기의 앱 전용 저장 공간에 담기며, 어디로도 전송되지 않습니다.

[옵션 > 백업과 복원]에서 만드는 백업 파일(.recipebak)에는 저장된 모든 레시피와 버전, 조리 기록·맛 평가, 그리고 줄이지 않은 원본 사진이 함께 들어갑니다. 만든 파일은 사용자가 공유 창에서 고른 앱이나 저장 위치(드라이브·파일 앱 등)로만 전달되며, 개발자에게는 전송되지 않습니다 — 옮긴 뒤 그 파일을 어디에 두는지는 사용자가 정합니다.

복원할 때는 기기의 파일 선택 화면이 열리고, 사용자가 직접 고른 파일 하나만 읽습니다. 앱이 기기의 다른 파일을 뒤지거나 목록을 읽는 일은 없습니다. 고른 파일은 읽는 동안만 앱 임시 폴더에 복사했다가 곧바로 지웁니다. 복원은 지금 기기에 있는 레시피·조리 기록·사진을 모두 지우고 백업 속 내용으로 바꾸므로, 되돌리기 전에 한 번 더 확인을 받습니다.

4. 인터넷 연결을 사용하는 경우

이 앱은 인터넷 없이 모든 기능이 동작합니다. 앱이 개발자의 서버로 보내는 데이터는 없으며, 앱이 스스로 인터넷에 접속하는 일도 없습니다. 도움말이나 옵션에서 개인정보처리방침 링크나 앱이소 소개 페이지를 누르면 기기의 브라우저로 해당 페이지가 열리고, 문의 메일 주소를 누르면 기기의 메일 앱이 열립니다 — 사용자가 직접 눌렀을 때만 일어납니다.

5. 제3자 제공 및 권한

  • 수집하는 정보가 없으므로 제3자에게 제공하거나 판매하는 정보도 없습니다.
  • 위치·연락처·마이크에 접근하지 않습니다.
  • 카메라는 사용자가 조리 단계나 완성 요리를 찍으려고 카메라 버튼을 눌렀을 때만 열립니다. 찍은 사진은 이 기기의 앱 전용 저장 공간에만 보관됩니다.
  • 저장소 접근 권한을 요구하지 않습니다. 백업 파일을 내보낼 때는 공유 창을, 복원할 때는 기기의 파일 선택 화면을 쓰기 때문에, 앱은 사용자가 그때 고른 파일 하나만 다룹니다.

6. 아동의 개인정보

이 앱은 연령과 관계없이 어떤 사용자의 개인정보도 수집하지 않습니다. 이름이나 나이를 입력받는 곳도 없습니다.

7. 방침 변경

방침이 바뀌면 이 페이지를 수정하고 위의 최종 수정일을 갱신합니다. 중요한 변경이 있으면 앱 업데이트 설명에도 적습니다.
