앱이소 경조사 개인정보처리방침

시행일: 2026년 9월 12일

1. 기기에 저장하는 정보

사용자가 입력한 상대 이름, 관계, 경조사 종류와 날짜, 행사 이름, 금액, 메모, 화면 설정, 그리고 잠금 설정(비밀번호의 해시값과 지문 사용 여부)을 앱 전용 저장소에 보관합니다. 비밀번호 원문은 저장하지 않습니다. 개발자 서버가 없으며 입력한 내용을 개발자에게 전송하지 않습니다. 가입, 광고, 결제, 분석·크래시 수집 SDK를 사용하지 않습니다.

2. 인터넷과 권한

이 앱은 인터넷 통신을 하지 않으며 네트워크 권한을 요청하지 않습니다. 지문·얼굴 인식(생체 인증) 권한은 사용자가 옵션에서 "지문으로 열기"를 켤 때만 기기의 인증 화면을 띄우는 데 쓰이며, 생체 정보 자체는 앱이 읽거나 저장하지 않고 안드로이드가 결과(성공·실패)만 알려 줍니다. 알림, 연락처, 위치, 사진, 마이크를 비롯한 다른 기기 권한은 요청하지 않습니다. 소개 페이지, 온라인 개인정보처리방침, 문의 메일은 사용자가 누를 때 기기의 브라우저 또는 메일 앱을 열어 보여 줄 뿐입니다.

3. 백업과 삭제

기록과 잠금 설정은 사용자 본인의 구글 계정 안드로이드 자동 백업에 포함될 수 있습니다. 백업은 안드로이드 플랫폼이 사용자 계정으로 수행하는 기능이며 개발자가 그 데이터를 받지 않습니다. 앱 안에서 기록을 지우면 즉시 삭제되고, 앱을 제거하거나 앱 데이터를 삭제하면 기록도 사라질 수 있습니다.

4. 외부 링크와 앱

소개 페이지·온라인 개인정보처리방침은 브라우저를, 문의 메일은 메일 앱을 사용자가 누를 때 엽니다. 외부 서비스에는 해당 서비스의 정책이 적용됩니다.
