앱이소 행복 개인정보처리방침

시행일: 2026년 9월 20일

1. 기기에 저장하는 정보

사용자가 선택적으로 입력한 나이대·성별·일상과 별명, 직접 선택한 오늘의 날씨, 오늘 나눈 대화(앱이 건넨 말), 보관함에 담은 말, 말을 받은 날의 수, 화면 테마 설정을 앱 전용 저장소에 보관합니다. 고른 기분은 그날 건넬 말을 고르는 데만 쓰며 날짜별로 기록하거나 모아서 보여주지 않습니다. 날씨는 직접 고른 값만 사용하며 위치나 기상 정보를 조회하지 않습니다. 날씨와 오늘의 대화는 날짜가 바뀌면 화면에서 제외하고 다음 저장 시 정리합니다. 개발자 서버가 없으며 입력한 내용을 개발자에게 전송하지 않습니다. 가입, 로그인, 광고, 결제, 분석·크래시 수집 SDK를 사용하지 않고 인터넷 권한도 요청하지 않습니다.

2. 권한과 공유

이 앱은 Android 권한을 요청하지 않습니다. 연락처, 위치, 사진, 마이크, 알림 등 어떤 권한도 쓰지 않습니다. 사용자가 말풍선 아래 공유 버튼을 누르면 Android 공유 화면이 열리고, 사용자가 고른 앱으로 그 편의 네 마디와 전해 오는 말의 출처 표기가 전달됩니다. 이 과정은 사용자가 누를 때만 일어나며 앱이 스스로 무엇도 보내지 않습니다.

3. 백업과 삭제

Android 자동 백업이 켜져 있으면 앱 데이터가 사용자 본인의 Google 계정 백업에 포함될 수 있습니다. 백업은 Android 플랫폼 기능이며 개발자는 그 내용을 받지 않습니다. 옵션의 [모두 지우고 처음부터]로 프로필과 보관함을 포함한 모든 데이터를 앱 안에서 직접 삭제할 수 있고, 앱 제거 또는 데이터 삭제 시에도 삭제됩니다.

4. 외부 링크

소개 페이지, 온라인 개인정보처리방침과 문의 메일은 사용자가 누를 때 외부 브라우저 또는 메일 앱에서 열립니다. 외부 서비스에는 해당 서비스의 정책이 적용됩니다.
