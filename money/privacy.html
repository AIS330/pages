가계부 개인정보처리방침

시행일: 2026-08-23

「가계부」(패키지명 com.appiso.money, 이하 "앱")는 서버 없이 동작하는 오프라인 가계부 앱입니다. 개발자는 이용자의 개인정보를 수집하지 않습니다.

1. 수집하는 개인정보

없습니다. 앱에는 회원가입·로그인이 없고, 분석·광고·크래시 리포팅 SDK를 사용하지 않으며, 이용자의 어떤 데이터도 개발자나 제3자의 서버로 전송하지 않습니다.

2. 기기에만 저장되는 데이터

이용자가 입력한 거래 내역, 장부, 카테고리, 계좌 정보는 이용자 기기의 앱 전용 저장 공간(로컬 CSV/JSON 파일)에만 저장됩니다. 개발자는 이 데이터에 접근할 수 없습니다. 앱을 삭제하면 함께 삭제되며, Android 자동 백업 대상에서도 제외되어 있습니다(allowBackup=false).

3. SMS 권한 (Android, 선택 기능)

카드 승인 문자를 거래로 자동 등록하는 선택 기능을 위해 SMS 수신 권한(RECEIVE_SMS)을 사용합니다.

  • 기능은 기본적으로 꺼져 있으며, 이용자가 설정에서 직접 켤 때만 권한을 요청합니다.
  • 앱은 문자 보관함(받은 문자함)을 읽지 않습니다. 기능이 켜진 동안 새로 수신되는 문자만 확인하여, 이용자가 설정한 필터에 맞는 카드 승인 문자를 기기 안에서 분석해 거래로 기록합니다.
  • 문자 내용은 어떤 경우에도 기기 밖으로 전송되지 않습니다.
  • 기능을 끄면 문자 확인이 즉시 중단되며, 앱에 보관된 문자 기록은 앱 안에서 삭제할 수 있습니다.

4. 네트워크 사용

외화 결제 문자를 원화로 환산할 때 환율 조회를 위해 공개 환율 API (open.er-api.com)에 접속합니다. 이때 전송되는 정보는 통화 코드(예: USD)뿐이며, 금액·가맹점·기기 정보 등 개인정보는 포함되지 않습니다.

5. 백업 파일

백업은 이용자가 직접 실행할 때만 만들어지며, 이용자가 지정한 위치에 암호화된 zip 파일로 저장됩니다. 개발자는 백업 파일에 접근할 수 없습니다.
