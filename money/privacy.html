앱이소 가계부 개인정보처리방침

시행일: 2026년 8월 23일 · 최종 수정일: 2026년 9월 3일

요약 — 앱이소 가계부(패키지명 com.appiso.money)는 개인정보를 수집하지 않습니다. 계정도, 로그인도, 광고도, 분석 도구도, 서버도 없습니다. 기록한 거래와 카드 승인 문자는 모두 사용자의 기기 안에서만 처리되고, 개발자를 포함한 누구에게도 전송되지 않습니다.

1. 수집하는 개인정보

  • 이 앱은 이름, 이메일, 전화번호, 위치, 연락처 등 어떤 개인정보도 수집하지 않습니다.
  • 회원가입·로그인 기능이 없으며 사용자를 식별하지 않습니다.
  • 분석·광고·크래시 리포팅 SDK를 사용하지 않고, 이용자의 어떤 데이터도 개발자나 제3자의 서버로 전송하지 않습니다.

2. 기기에만 저장되는 데이터

이용자가 입력한 거래 내역, 장부, 카테고리, 계좌 정보는 이용자 기기의 앱 전용 저장 공간 (로컬 CSV/JSON 파일)에만 저장됩니다. 개발자는 이 데이터에 접근할 수 없습니다. 앱을 삭제하면 함께 삭제되며, 안드로이드 자동 백업 대상에서도 제외되어 있습니다(allowBackup=false) — 금융 기록이 이용자 모르게 클라우드로 올라가지 않도록 한 것입니다.

PC(윈도우) 버전은 사용자 계정의 앱 데이터 폴더(AppData)에 저장하며, 문서 폴더나 클라우드 동기화 폴더에는 두지 않습니다.

3. SMS 권한 (안드로이드, 선택 기능)

카드 승인 문자를 거래로 자동 등록하는 선택 기능을 위해 SMS 수신 권한 (RECEIVE_SMS)을 사용합니다.

  • 기능은 기본적으로 꺼져 있으며, 이용자가 설정에서 직접 켤 때만 권한을 요청합니다.
  • 앱은 문자 보관함(받은 문자함)을 읽지 않습니다(READ_SMS 권한 없음). 기능이 켜진 동안 새로 수신되는 문자만 확인하여, 이용자가 설정한 발신자·키워드 필터에 맞는 카드 승인 문자만 기기 안에서 분석해 거래로 기록합니다. 필터에 맞지 않는 문자는 저장하지 않습니다.
  • 문자 내용은 어떤 경우에도 기기 밖으로 전송되지 않습니다.
  • 모든 장부에서 기능을 끄면 문자 확인이 즉시 중단되고, 아직 처리하지 않은 문자도 함께 삭제됩니다. 앱에 보관된 미인식 문자 기록은 앱 안에서 삭제할 수 있습니다.

4. 네트워크 사용

외화 결제 문자를 원화로 환산할 때 환율 조회를 위해 공개 환율 API(open.er-api.com)에 접속합니다. 이때 전송되는 정보는 통화 코드(예: USD)뿐이며, 금액·가맹점·기기 정보 등 개인정보는 포함되지 않습니다. 그 밖에 앱이 스스로 인터넷에 접속하는 일은 없습니다. 도움말이나 설정에서 개인정보처리방침 링크를 누르면 기기의 브라우저로 이 페이지가 열립니다 — 이용자가 직접 눌렀을 때만 일어납니다.

5. 백업 파일

백업은 이용자가 직접 실행할 때만 만들어지며, 이용자가 지정한 위치에 zip 파일로 저장됩니다. 백업 시 비밀번호를 설정하면 파일이 암호화되며(선택), 비밀번호는 저장되지 않습니다. 개발자는 백업 파일에 접근할 수 없습니다. 클라우드 계정과 직접 연동하는 기능은 없습니다.

6. 아동의 개인정보

이 앱은 연령과 관계없이 어떤 사용자의 개인정보도 수집하지 않습니다. 이름이나 나이를 입력받는 곳도 없습니다.

7. 방침 변경

방침이 바뀌면 이 페이지를 수정하고 위의 최종 수정일을 갱신합니다. 중요한 변경이 있으면 앱 업데이트 설명에도 적습니다.

English summary

Appiso Money (앱이소 가계부, package com.appiso.money) does not collect any personal data. There is no account, no login, no advertising, no analytics, and no server. Your ledgers, transactions and accounts are stored only in the app's private storage on your own device and are excluded from Android auto backup. The optional card-SMS feature uses RECEIVE_SMS only (never READ_SMS): while enabled, newly received messages matching your own sender/keyword filters are parsed on-device into expense entries; no message content ever leaves the device, and turning the feature off stops capture immediately and discards any unprocessed messages. The only network request is an exchange-rate lookup that sends a currency code (e.g. USD) and nothing else. Backups are zip files you create yourself (optionally encrypted with a password that is never stored). Contact: appisoLabs@gmail.com
