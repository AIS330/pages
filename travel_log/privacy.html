앱이소 여행 기록 개인정보처리방침

시행일: 2026년 9월 18일

1. 기기에 저장하는 정보

사용자가 입력한 여행 이름, 여행지, 기간, 통화, 예산, 메모와 여행 안의 기록(장소 종류·이름·주소·메모·별점·방문일·사진), 일정(날짜·시각·제목·메모·분류·예상 금액·실제 금액), 화면 설정을 앱 전용 저장소에 보관합니다. 개발자 서버가 없으며 입력한 내용을 개발자에게 전송하지 않습니다. 가입, 광고, 결제, 분석·크래시 수집 SDK를 사용하지 않습니다.

2. 인터넷 사용

이 앱은 네트워크 권한을 요청하지 않으며 인터넷을 사용하지 않습니다. 모든 기능은 인터넷 없이 동작합니다. 개인정보처리방침·앱이소 소개 페이지·문의 메일은 사용자가 누를 때 브라우저 또는 메일 앱에 넘겨 엽니다.

3. 사진

사용자가 시스템 카메라로 촬영하거나 시스템 사진 선택기로 고른 사진만 기록당 최대 10장 보관합니다. 갤러리 원본을 변경하거나 삭제하지 않으며, 전체 사진 라이브러리를 읽는 권한을 요청하지 않습니다. 저장하는 사본에서는 촬영 위치·기기 정보 같은 메타데이터를 제거합니다.

4. 공유

공유는 사용자가 공유 버튼을 눌렀을 때만 일어나며, 사용자가 고른 여행 전체 또는 종류별 기록을 텍스트나 앱 파일로 만들어 사용자가 선택한 앱(메신저, 메일 등)에 넘깁니다. 공유 내용에 사용자의 현재 위치나 기기 정보는 담지 않습니다. 다른 사람이 보낸 앱 파일은 사용자가 확인한 뒤에만 기기 안에 추가합니다.

5. 백업과 삭제

여행 기록은 사용자 본인의 구글 계정 자동 백업에 포함될 수 있으며, 사진은 자동 클라우드 백업에서 제외됩니다. Android 기기 간 직접 이전에는 사진도 포함될 수 있습니다. 사진까지 옮기려면 앱 안의 백업 파일 내보내기·복원을 사용하며, 백업 파일은 사용자가 고른 곳에만 저장되고 개발자에게 전송되지 않습니다. 여행을 지우면 안에 든 기록·일정·사진 사본도 삭제합니다. 앱을 제거하거나 데이터를 삭제하면 기록과 사진도 사라질 수 있습니다.

6. 외부 링크와 앱

소개 페이지·온라인 개인정보처리방침·문의 메일은 브라우저 또는 메일 앱을 사용자가 누를 때 엽니다. 외부 서비스에는 해당 서비스의 정책이 적용됩니다.
