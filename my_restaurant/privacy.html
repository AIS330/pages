앱이소 나의 맛집 개인정보처리방침

시행일: 2026년 9월 9일

1. 기기에 저장하는 정보

사용자가 입력한 맛집 이름, 주소, 전화번호, 메뉴, 설명, 가격대, 맛집의 위치 좌표, 사진, 평가(사용자가 적은 이름·별점·내용)와 화면 설정을 앱 전용 저장소에 보관합니다. 평가에 적는 이름은 사용자가 직접 입력하는 표시용 이름이며 계정이나 연락처와 연결되지 않습니다. 개발자 서버가 없으며 입력한 내용을 개발자에게 전송하지 않습니다. 가입, 광고, 결제, 분석·크래시 수집 SDK를 사용하지 않습니다.

2. 위치

"내 주변" 필터와 "현재 위치로 등록"을 사용자가 누를 때만 기기의 위치를 한 번 읽습니다. 저장하는 것은 사용자가 등록한 맛집의 좌표뿐이며, 사용자의 위치 이력은 기록하거나 전송하지 않습니다. 위치 권한을 허용하지 않아도 나머지 기능은 모두 사용할 수 있습니다.

3. 사진

사용자가 시스템 카메라로 촬영하거나 시스템 사진 선택기로 고른 사진만 맛집당 최대 5장 보관합니다. 갤러리 원본을 변경하거나 삭제하지 않으며, 전체 사진 라이브러리를 읽는 권한을 요청하지 않습니다.

4. 인터넷 사용

앱 안 지도의 배경 지도 타일은 인터넷이 연결됐을 때 OpenStreetMap 공개 서버에서 받아옵니다. 이때 보내는 것은 보고 있는 지도 영역의 타일 좌표와 앱 식별 정보뿐이며, 맛집 기록이나 사용자 정보는 보내지 않습니다. 인터넷이 없으면 배경 없이 핀만 표시되고 나머지 기능은 그대로 동작합니다. 맛집을 적을 때 사용자가 [주소로 찾기]를 누르면 입력한 주소 문자열만 OpenStreetMap Nominatim 공개 서버에 보내 좌표를 받아옵니다. 이 요청에는 앱 식별 정보(앱 이름·버전·문의 메일)만 붙으며, 다른 기록이나 사용자의 위치는 보내지 않습니다.

5. 공유

공유는 사용자가 공유 버튼을 눌렀을 때만 일어나며, 사용자가 고른 맛집 정보(평가를 남긴 이름·별점·내용 포함)를 텍스트, 이미지 또는 앱 파일로 만들어 사용자가 선택한 앱(메신저, 메일 등)에 넘깁니다. 공유 내용에 사용자의 현재 위치나 기기 정보는 담지 않습니다. 다른 사람이 보낸 앱 파일은 사용자가 확인한 뒤에만 기기 안에 추가합니다.

6. 백업과 삭제

맛집 기록은 사용자 본인의 구글 계정 자동 백업에 포함될 수 있으며, 사진은 자동 클라우드 백업에서 제외됩니다. Android 기기 간 직접 이전에는 사진도 포함될 수 있습니다. 맛집을 지우면 연결된 사진 사본도 삭제합니다. 앱을 제거하거나 데이터를 삭제하면 기록과 사진도 사라질 수 있습니다.

7. 외부 링크와 앱

주소를 누르면 지도 앱을, 전화번호를 누르면 전화 앱을, 소개 페이지·온라인 개인정보처리방침·문의 메일은 브라우저 또는 메일 앱을 사용자가 누를 때 엽니다. 외부 서비스에는 해당 서비스의 정책이 적용됩니다.
