앱이소 디데이 개인정보처리방침

시행일: 2026년 9월 7일

1. 기기에 저장하는 정보

사용자가 입력한 일정, 동행인, 장소, 메모, 준비물, 사진과 화면·알림 설정을 앱 전용 저장소에 보관합니다. 개발자 서버가 없으며 입력한 내용을 개발자에게 전송하지 않습니다. 가입, 광고, 결제, 분석·크래시 수집 SDK를 사용하지 않습니다.

2. 사진

사용자가 시스템 카메라로 촬영하거나 시스템 사진 선택기로 고른 사진만 일정당 최대 5장 보관합니다. 긴 변 2,048px 이내로 조정하고 PNG 사본으로 저장합니다. 갤러리 원본을 변경하거나 삭제하지 않습니다. 사진 메타데이터를 사본에 복사하지 않습니다.

3. 알림과 권한

사용자가 선택한 미리 알림을 Android 기기에서 예약합니다. 알림 표시 및 정확한 알람 권한을 사용자가 허용할 수 있습니다. 기기 재부팅 후 예약 복원 수신기를 사용합니다. 연락처나 전체 사진 라이브러리를 읽는 권한을 요청하지 않습니다.

4. 백업과 삭제

자동 클라우드 백업에서는 제외합니다. Android 기기 간 직접 이전에 앱 데이터가 포함될 수 있습니다. 일정이나 사진을 삭제하면 연결된 앱 사본을 삭제합니다. 앱 제거 또는 데이터 삭제 시 기록과 사진도 삭제될 수 있습니다. 현재 버전에는 수동 파일 백업·복원이 없습니다.

5. 외부 링크

소개 페이지, 온라인 개인정보처리방침과 문의 메일은 사용자가 누를 때 외부 브라우저 또는 메일 앱에서 열립니다. 외부 서비스에는 해당 서비스의 정책이 적용됩니다. 일정과 사진을 자동으로 전송하지 않습니다.
